To alter and add profiles, create a JSON, with the key you want them to press under each thing. it should look like this:
{
    "key1": ["h", 100, 0, 1],
}

the first value is the pressed key,
the second is his chance of choosing it per cycle,
the third is the minimum time held,
the fourth is the max time held

write the name of your profile in options.json to use it
